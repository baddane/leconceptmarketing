Comment accepter Bitcoin sur WordPress – Votre guide étape par étape

    Bien que le bitcoin soit imprévisible, sa valeur et son utilisation grand public n’ont cessé d’augmenter, à la grande satisfaction de ceux qui possèdent les pièces. De plus, de nombreux consommateurs, entreprises et même processeurs de paiement ont commencé à reconnaître Bitcoin comme une méthode de paiement viable, et c’est pourquoi de plus en plus d’entreprises en ligne veulent apprendre comment accepter Bitcoin sur WordPress.

    Par exemple, un spécialiste du marketing de contenu pourrait vendre des abonnements premium et accepter Bitcoin comme paiement alternatif, ou un magasin en ligne pourrait placer un bouton Bitcoin à côté du champ de la carte de crédit. Même les blogueurs et les organisations caritatives pourraient demander un don en bitcoins, avec la possibilité de l’encaisser immédiatement ou d’attendre de voir la valeur de ce paiement augmenter avec le temps.

    La principale raison d’accepter Bitcoin sur WordPress, cependant, est son accessibilité à tous.

    Comme beaucoup d’entre nous le savent, WordPress permet aux utilisateurs de créer des sites de commerce électronique avec un plugin comme WooCommerce. WooCommerce se connecte à de nombreuses passerelles de paiement comme Stripe, PayPal et Payoneer.

    Le seul problème est que certains clients dans d’autres pays ne sont pas en mesure d’utiliser ces passerelles de paiement, alors que Bitcoin est accessible à tous. En outre, certains consommateurs préfèrent payer en bitcoins (plutôt qu’avec une carte de crédit), ce qui constitue un autre moyen de garantir les ventes.

    Quelles sont les autres raisons d’accepter Bitcoin sur WordPress ?

    Outre la possibilité d’accepter les paiements d’un plus grand nombre de clients et son potentiel d’amélioration des transactions internationales, Bitcoin offre quelques autres avantages intéressants :

    • Bitcoin est numérique et décentralisé. Par conséquent, vous n’avez pas besoin de faire appel à une banque tierce, mais les transactions sont sécurisées et quelque peu anonymes grâce à l’utilisation d’un grand livre appelé blockchain.
    • Les paiements en bitcoin sont irréversibles et chaque transaction est accompagnée d’un code hexadécimal extrêmement difficile. Il y a donc moins de risques de piratage et de fraude.
    • Les transactions en bitcoins sont souvent assorties de frais moins élevés que lorsqu’on travaille avec des banques.
    • Si quelqu’un effectue un paiement en bitcoins sur votre site, tous les fonds sont immédiatement disponibles pour vous.
    • Vos clients (et vos bases de données) sont plus sûrs puisque les transactions en bitcoins ne stockent aucune information personnelle ou financière. Toutes les transactions sont enregistrées dans un grand livre public, mais il n’y a pas beaucoup plus d’informations partagées.

    Comment accepter Bitcoin sur WordPress :

    Après avoir décidé d’accepter les bitcoins sur WordPress (que ce soit pour les ventes en ligne, la facturation des clients ou les dons/abonnements pour votre blog), vous devez vous procurer un système de paiement en bitcoins.

    Voici comment cela fonctionne :

    1. Le système de paiement (appelé Blockonomics) vous permet d’accepter Bitcoin comme paiement, que ce soit avec un bouton Bitcoin intégré ou une méthode de paiement Bitcoin dans WooCommerce.
    2. Le client vous envoie le montant en bitcoins que vous avez demandé pour votre produit ou service.
    3. La commande est enregistrée dans Blockonomics et WordPress pour que vous puissiez l’exécuter.
    4. Le bitcoin est versé dans votre propre portefeuille.

    Configuration initiale : Créez un compte Blockonomics (et installez le plugin) pour accepter les bitcoins sur WordPress.

    Blockonomics est un outil qui aide les propriétaires de sites Web à accepter les paiements en bitcoin en ligne. Il possède :

    • Des boutons de paiement Bitcoin intégrables.
    • Une intégration de boutique en ligne pour offrir Bitcoin comme méthode de paiement.
    • Un plugin WordPress pour rendre ces deux fonctionnalités plus transparentes.
    • La première étape consiste donc à installer le plugin WordPress Bitcoin Payment – Blockonomics sur votre site WordPress. Lisez notre guide d’installation des plugins WordPress si vous avez des questions.

    La première étape consiste donc à installer le plugin WordPress Bitcoin Payment – Blockonomics sur votre site WordPress. Lisez notre guide sur l’installation des plugins WordPress si vous avez des questions.

    Après avoir installé et activé le plugin, allez dans Paramètres > Blockonomics.

    Ici, le plugin affiche un champ pour la clé API. Vous pouvez également générer automatiquement une URL de rappel. La clé API relie simplement votre site WordPress à Blockonomics ; vous n’avez pas besoin de savoir quoi que ce soit sur l’API, juste de trouver la clé API dans Blockonomics.

    Vous devez créer un compte Blockonomics afin de générer une clé API, de créer des boutons d’achat en bitcoin et d’insérer Bitcoin comme méthode de paiement dans WooCommerce. Cliquez sur ce lien ou utilisez le lien dans WordPress pour accéder à la page Blockonomics Merchant.

    Cliquez sur le bouton “Get Started For Free” pour continuer.

    Créez un compte avec votre adresse e-mail et un mot de passe fort. Cliquez sur Enregistrer pour continuer.

    Une fois que le compte est actif, cliquez sur Stores, puis copiez la clé API que vous voyez sur la page.

    Revenez à la page WordPress Blockonomics et collez ce code dans le champ API Key. Cliquez sur Enregistrer. Votre site WordPress est maintenant prêt à utiliser les outils de traitement des paiements de Blockonomics.

    Configuration initiale, partie 2 : Obtenir un porte-monnaie Bitcoin avec des capacités xPub

    Pour chaque méthode de cet article, vous avez besoin d’un portefeuille Bitcoin pour stocker les bitcoins qui vous sont versés pour les transactions. Blockonomics utilise deux éléments pour transférer de l’argent sur votre compte : une adresse xPub et une adresse de portefeuille Bitcoin type. Étant donné que les transactions Bitcoin génèrent toujours une nouvelle adresse de portefeuille de réception, il est essentiel d’avoir l’adresse xPub pour que les transactions fonctionnent à partir de plusieurs clients à la suite.

    👉🏼 Lecture complémentaire : Comment évaluer une cryptomonnaie : Le Guide Ultime

    Il est donc nécessaire d’avoir un porte-monnaie Bitcoin qui donne accès à une adresse xPub, sinon il est assez difficile d’accepter des paiements Bitcoin en ligne. Pour obtenir un porte-monnaie Bitcoin compatible, nous vous recommandons d’utiliser l’une des méthodes suivantes :

    Examinez tous les portefeuilles Bitcoin que vous possédez actuellement, comme Exodus, Trezor, Ledger ou Blockchain.com. Si vous possédez déjà l’un de ces portefeuilles, il n’est pas nécessaire d’en créer un nouveau ; vous pouvez déjà obtenir l’adresse xPub à partir de ceux-ci. Voici un article sur les portefeuilles pris en charge et sur la façon d’obtenir les adresses xPub. (De nombreux portefeuilles que vous recevez d’échanges comme Binance et Coinbase ne fournissent pas d’adresses xPub et ne peuvent donc pas fonctionner avec Blockonomics).
    Ou… ouvrez un compte Blockchain.com si vous n’avez pas déjà un porte-monnaie mentionné ci-dessus ; Blockchain.com est un fournisseur de porte-monnaie sûr et réputé qui prend en charge xPub.

    Méthode 1 : Accepter Bitcoin sur WordPress avec des boutons de paiement intégrables


    Certains propriétaires de sites n’ont pas besoin d’une boutique en ligne complète, mais ils aimeraient vendre un ou deux produits. Dans ce cas, il n’est pas nécessaire d’installer quelque chose comme WooCommerce. Il suffit d’intégrer un bouton d’achat Bitcoin n’importe où sur votre site, par exemple au début d’une page de renvoi, à la fin d’un article de blog ou sur votre page d’accueil. Vous pouvez utiliser cette méthode pour les dons et les ventes rapides de produits/services.

    Après vous être connecté à votre compte, rendez-vous sur le tableau de bord de Blockonomics. La page d’accueil propose deux options pour l’acceptation des paiements. Choisissez celle qui consiste à créer un bouton/lien de paiement. Vous pouvez également aller directement à l’élément de menu Boutons/liens de paiement sur la gauche ; les deux vous amènent au même endroit.

    La page Boutons/liens de paiement vous demande de remplir trois champs :

    • Portefeuille de destination xPub
    • Exemple d’adresse de réception (ce champ apparaît après que vous ayez saisi un xPub valide)
    • Étiquette

    Pour trouver l’adresse xPub, allez dans votre portefeuille Bitcoin (nous avons recommandé Blockchain.com plus tôt, mais des portefeuilles comme Trezor et Ledger fonctionnent bien aussi).

    La façon de trouver l’adresse xPub varie d’un portefeuille à l’autre. Nous vous recommandons donc de consulter cet article en fonction du portefeuille utilisé.

    Pour Blockchain.com, vous cliquez sur l’icône des paramètres utilisateur dans le coin supérieur droit. Ensuite, allez dans Portefeuilles et adresses > Gérer (à côté du portefeuille de clés privées) > Gérer (il s’agit d’un nouveau lien déroulant) > Afficher xPub.

    Copiez le code xPub, puis collez-le dans le champ xPub de Blockonomics.

    dresse de réception Bitcoin standard, comme vous le feriez pour accepter n’importe quel paiement Bitcoin. La plupart des portefeuilles disposent d’un bouton Recevoir permettant de générer une adresse de réception type.

    Par exemple, sur Blockchain.com, vous pouvez cliquer sur Receive.

    Ensuite, recherchez Bitcoin et cliquez sur un porte-monnaie à clé privée. Copiez l’adresse de réception de la page résultante.

    Retournez dans Blockonomics, et collez l’exemple d’adresse de réception. Remplissez le champ Étiquette avec le nom que vous voulez ; ceci est pour votre propre référence. Cliquez sur Enregistrer les modifications.

    Vous êtes maintenant prêt à créer un bouton de paiement en bitcoins. Cliquez sur l’onglet Produits dans Blockonomics. Remplissez le contenu/les champs que vous souhaitez afficher avec votre produit :

    • Nom du produit
    • Description du produit
    • Champs client obligatoires pour le paiement
    • Code du produit
    • Prix (vous pouvez l’afficher en USD amais le paiement est effectué en Bitcoin)
    • Mode de don
    • Courriel de fin de commande
    • Lorsque vous avez configuré votre produit, cliquez sur l’option Générer un bouton. Il existe également des boutons pour créer des URL et des widgets.

    Copiez le premier bloc de code fourni, puis collez-le où vous voulez sur votre site WordPress.

    Par exemple, vous pouvez utiliser le bloc HTML dans WordPress sur une page ou un article.

    Vous devez également ajouter le code de l’étape 2 de Blockonomics en bas de votre page WordPress. Encore une fois, vous pouvez l’ajouter dans un bloc HTML personnalisé (c’est un code caché qui ne rend rien sur le frontend).

    Après avoir enregistré les modifications dans WordPress, un bouton “Pay With Bitcoin” apparaît maintenant sur le front-end de votre page WordPress.

    Lorsqu’on clique dessus, une fenêtre contextuelle s’affiche pour collecter les champs de détails du client que vous avez spécifiés. Le client clique pour payer le produit.

    Enfin, ils voient un code QR pour payer à partir de leur propre portefeuille Bitcoin mobile. Ils ont également la possibilité d’utiliser l’adresse Bitcoin fournie. Ce qui est bien avec Blockonomics, c’est qu’il fournit des prix en USD et en Bitcoin.

    Méthode 2 : Accepter Bitcoin sur un site WordPress utilisant WooCommerce

    La deuxième façon d’accepter Bitcoin sur WordPress est en tant que méthode de paiement dans WooCommerce. Cela signifie que vous exécutez une boutique en ligne, où le client ajoute des articles à son panier, vérifie, et voit des méthodes de paiement comme la carte de crédit, PayPal, et Bitcoin.

    👉🏼 Lecture complémentaire :  3 Astuces Pour Protéger Votre Site WordPress Contre Les Spams

    Ce qui est utile en ajoutant Blockonomics à WooCommerce, c’est que toutes les commandes en Bitcoin sont enregistrées, de sorte que vous pouvez les exécuter comme n’importe quelle autre commande.

    Pour commencer, allez sur Blockonomics et cliquez sur l’élément de menu Stores. Choisissez l’option Ajouter un nouveau magasin.

    Les meilleurs brokers crypto-monnaie & Bitcoin en 2022 :

    • Binance
    • bitFlyer

    Vous pouvez ajouter plusieurs magasins, mais sachez que vous devez avoir au moins un magasin actif dans Blockonomics pour qu’il fonctionne avec WooCommerce.

    Pour ajouter un magasin, remplissez les champs suivants :

    • Portefeuille de destination xPub
    • Adresse de réception de l’échantillon
    • Balise
    • URL de rappel HTTP

    Vous pouvez trouver l’adresse xPub sur Blockchain.com en cliquant sur l’icône des paramètres utilisateur dans le coin supérieur droit. Ensuite, allez dans Portefeuilles et adresses > Gérer (à côté du portefeuille de clés privées) > Gérer (il s’agit d’un nouveau lien déroulant) > Afficher xPub.

    Vous pouvez également trouver l’adresse xPub pour d’autres portefeuilles que vous pouvez utiliser (comme Ledger ou Trezor) en lisant ce guide.

    Copiez le code xPub du portefeuille et collez-le dans Blockonomics.

    Pour trouver un exemple d’adresse de réception, vous pouvez généralement cliquer sur le bouton Recevoir de votre portefeuille pour générer une nouvelle adresse Bitcoin (comme vous le feriez pour un transfert Bitcoin standard). Blockchain.com est également une excellente option pour cela.

    Enfin, vous pouvez trouver l’URL de rappel dans WordPress. Allez dans Réglages > Blockchain. Copiez l’URL de rappel, puis retournez à Blockonomics et collez-la dans le champ de droite.

    Avec tout cela, vous devriez avoir rempli chaque champ. Cliquez sur le bouton “Enregistrer les modifications”.

    Vous verrez maintenant votre nouveau magasin affiché dans Blockonomics.

    👉🏼 Lecture complémentaire : Next Earth Avis : Immobilier virtuel, Metaverse et plus encore

    Il y a même un bouton “Test Setup” dans la page WordPress Blockonomics pour vérifier si vous avez saisi des adresses Bitcoin valides.

    Une autre façon de vérifier la connexion est d’aller dans WooCommerce > Paramètres > Paiements, où WooCommerce affiche maintenant une méthode de paiement Bitcoin (assurez-vous qu’elle est activée).

    Lorsque les paiements en bitcoins sont actifs, les clients ajoutent des produits à leur panier et voient apparaître une option de paiement en bitcoins à côté d’autres méthodes comme la carte de crédit et PayPal.

    Ils peuvent ensuite cliquer sur le bouton “Pay With Bitcoin”.

    Enfin, votre boutique affiche le prix exact de la transaction (en USD et en BTC) ainsi qu’un code QR pour le paiement instantané et une adresse Bitcoin pour effectuer le transfert depuis leur propre portefeuille.

    La dernière étape pour les deux méthodes : vérifier et exécuter les commandes.

    L’avantage de Blockonomics est qu’il enregistre toutes les commandes payées en bitcoins. Pour les boutons de paiement, vous pouvez cliquer sur l’onglet Commandes dans Blockonomics pour voir les commandes telles qu’elles apparaissent.

    Les commandes de bitcoins qui passent par votre magasin WooCommerce sont enregistrées à la fois dans Blockonomics et dans votre page de commandes WooCommerce. De cette façon, vous êtes informé et pouvez exécuter chaque commande immédiatement !

    Maintenant, c’est votre tour !
    Ce sont les principales étapes que vous devrez suivre pour accepter les bitcoins sur WordPress !
