YouTube vient d’ajouter de nouvelles options de filtrage concernant les commentaires dans le YouTube Studio, cela signifie que tous les propriétaires et les administrateurs des chaînes youtube peuvent identifier facilement les réponses vidéo présentant une opportunité ou reflétant un intérêt. Comme l’indique la photo ci-dessous :

[![Youtube Vient D'annoncer Une Nouvelle Option Pour Les Commentaires](https://www.socialmediatoday.com/user_media/diveimage/youtube_comment_filters.gif)](https://support.google.com/youtube/thread/15375630?hl=en)

Vous pourrez donc selon YouTube, désormais filtrer vos commentaires vidéo selon les catégories suivantes :

-   Commentaires avec questions
-   États des réponses
-   Statut des membres
-   Nombre des abonnés
-   Statut des abonnés  
    

Voici la déclaration officielle Youtube , Découvrez la source **[Ici](https://support.google.com/youtube/thread/15375786?hl=fr)** :

**Pour utiliser les filtres de recherche** : accédez à YouTube Studio sur un ordinateur. Dans le menu de gauche, sélectionnez l’onglet “Commentaires” et utilisez la barre de filtre en haut de la page. Vous pouvez combiner plusieurs filtres pour affiner votre recherche et trouver des commentaires spécifiques.**Nous intégrons également une autre fonctionnalité très demandée.** Auparavant, la recherche par mot clé n’affichait que les commentaires contenant une correspondance exacte. Désormais, les résultats incluent aussi les correspondances partielles. Autrement dit, si vous recherchez le terme “abonné”, vous obtiendrez les commentaires contenant ce mot, mais aussi ceux où figurent “abonnée” et “abonnées”. **Nous prévoyons de vous proposer davantage d’options de filtrage à l’avenir.** N’hésitez pas à laisser un commentaire ci-dessous pour nous indiquer celles qui vous seraient le plus utiles pour gérer vos commentaires.  
Nous espérons que vous apprécierez cette mise à jour.
