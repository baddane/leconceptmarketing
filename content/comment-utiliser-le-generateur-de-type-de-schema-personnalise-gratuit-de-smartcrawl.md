## Comment configurer un type de schéma personnalisé

Tout commence sur le tableau de bord de SmartCrawl. De là, dirigez-vous vers **Schéma**. Puis dans le **Générateur de types** section, vous cliquerez **Ajouter un nouveau type**.

![Ajouter un nouveau bouton de type.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173933_452_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Un clic vous permet de démarrer.

Cela vous amène à tous les types de schémas disponibles. Considérant que vous souhaitez en créer un personnalisé, vous cliquerez sur le bouton **Type personnalisé** option.

![Le bouton de type personnalisé.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173933_959_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Le type personnalisé est situé vers le bas.

Donnez au type de schéma un **Nom**. Il est préférable d’utiliser quelque chose associé au type de schéma, afin que vous sachiez exactement de quoi il s’agit.

![Où vous nommez le schéma.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173933_213_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Le nom par défaut est Type personnalisé – mais nommez-le comme vous le souhaitez pour l’identifier.

Le nom et d’autres modifications peuvent être apportées à tout moment (ce que nous aborderons plus loin dans cet article).

## Configuration du type de schéma

Ensuite, vous ajouterez **Règles**. Cet ensemble de règles détermine où le type de schéma sera activé ou exclu.

Cela consiste à configurer le type de schéma en définissant les conditions qui doivent être définies et toute page, publication ou taxonomie qui correspond à l’ensemble des exigences pour attribuer les informations au type de schéma personnalisé.

![Ajoutez une zone de type schéma.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173934_782_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Il existe de nombreuses variantes parmi lesquelles choisir.

La boîte de règle a une liste déroulante d’options, y compris **Afficher globalement**, **Page d’accueil**, **Catégorie**, et plus. Vous choisirez ensuite ce qu’il égalera (=).

Tout ce qui peut être combiné pour égaler la règle apparaîtra.

Vous pouvez toujours ajouter une règle en cliquant sur le **Et** bouton.

![La "et" bouton.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173934_273_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Cliquer sur “Et” ouvre une nouvelle règle.

De plus, vous pouvez avoir des règles Ou en cliquant sur **Ajouter une règle (ou)**.

![Bouton Ajouter une règle.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173934_178_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Le bouton Ajouter une règle (ou) crée également une nouvelle règle.

Pour en savoir plus sur la configuration des types de schéma, assurez-vous de lire notre documentation.

## Modification du type de schéma personnalisé

Une fois que votre nouveau type de schéma personnalisé est enregistré et prêt à fonctionner, il peut être modifié à tout moment. Il existe plusieurs façons d’éditer.

Premièrement, si jamais vous décidez de **désactiver** il, tout ce qu’il faut, c’est un clic. Il en va de même pour le réactiver. S’il est bleu, il est actif.

Il suffit d’un clic pour désactiver ou activer le schéma.

Besoin d’ajouter une propriété Simple, Imbriquée ou Collection ? Ou modifier une configuration ? Changer de lieu? Tout se fait depuis la liste déroulante.

![Le bouton déroulant.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173934_983_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

La liste déroulante vous permet de démarrer dans le processus d’édition des règles.

En cliquant sur le **Menu déroulant** ouvre toutes les règles et configurations, que vous pouvez modifier en conséquence.

![Où vous modifiez le schéma.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173934_336_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

## Duplication du type de schéma personnalisé

Lorsque vous **Dupliquer** votre type de schéma personnalisé, une autre version exacte apparaîtra immédiatement sous celle que vous avez dupliquée.

![Où vous dupliquez un type de schéma.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173934_246_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Comme vous pouvez le voir, il a le même nom, les mêmes caractéristiques, etc. – un clone exact de l’original.

Comme n’importe quel schéma, vous pouvez modifier le doublon en conséquence.

Si vous avez besoin d’apporter des modifications, accédez à **Générateur de types** dans la zone Schema de l’admin de SmartCrawl. Tous les schémas que vous avez pour votre site sont tous au même endroit !

## Exemple de type de schéma personnalisé

Maintenant que vous avez vu comment configurer un type de schéma personnalisé, voyons un exemple concret de cela. Pour commencer, tous les schémas disponibles sont à [schema.org](https://schema.org/). **Schéma.org** est une communauté qui a pour mission de créer, maintenir et promouvoir des schémas.

Nous allons utiliser un exemple de schema.org qui est assez courant : [restaurant](https://schema.org/Restaurant).

Comme vous pouvez le voir sur la page schema.org, il existe une tonne de catégories pour choisir les types de schéma.

![Une liste des types de schéma de restaurant.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173935_773_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Comme vous pouvez le voir sur la page, il y a beaucoup de choix. Il ne s’agit que d’une petite partie des types de schémas disponibles.

Ajoutez simplement les propriétés à votre type de schéma personnalisé dans SmartCrawl que vous souhaitez utiliser. Par exemple, nous avons le **adresse**, **Région**, **échelle des prix**, **logo**etc. — choses qui se rapportent à un restaurant.

![Un exemple de types de schéma de restaurant.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173935_467_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Vous pouvez voir que nous avons beaucoup ajouté à ce type de schéma de restaurant.

Vous avez les propriétés que vous souhaitez ? *Super!* Assurez-vous maintenant de tester votre type de schéma à [Test des résultats enrichis de Google](https://search.google.com/test/rich-results) ou la [Validateur de balisage de schéma](https://validator.schema.org/). Cela garantira que votre balisage de schéma fonctionne correctement.

![Test des résultats enrichis de Google.](https://leconceptmarketing.com/wp-content/uploads/2022/07/1659173935_448_Comment-utiliser-le-generateur-de-type-de-schema-personnalise-gratuit.png)

Comme vous pouvez le voir, tous nos types de schémas sont inclus.

Et c’est tout! Votre schéma personnalisé pour un restaurant est terminé et les clients définiront des réservations en un rien de temps.
