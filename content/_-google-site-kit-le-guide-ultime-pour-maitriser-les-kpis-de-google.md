Lors du [Wordcamp US](https://2019.us.wordcamp.org/), Google a présenté la version bêta de l’extension appelée « **[Google Site Kit](https://sitekit.withgoogle.com/)** » pour simplifier la vie aux utilisateurs de wordpress à partir du tableau de bord d’administration “WordPress Admin Panel”, Avec le fameux slogan : “**Bringing the best of Google  tools to WordPress**”.

## **1 –** l’**extension WordPress [Google Site Kit](https://sitekit.withgoogle.com/)**

![](https://leconceptmarketing.com/wp-content/uploads/2019/09/google-kit-pour-wordpress-1.jpeg)

Une extension qui vous permet “selon les équipes Google” de maîtriser, employer et adapter **[les KPIs](https://fr.wikipedia.org/wiki/Indicateur_cl%C3%A9_de_performance)** Google à vos objectifs et de suivre l’efficacité des produits Google.

## 2 – les produits concernés par [Site Kit de Google](https://sitekit.withgoogle.com/)

Google Site Kit récupère les données de performance de votre site web, et il les affiche directement et en temps réel sur votre tableau de bord d’administration WordPress.

[![](data:image/svg+xml;base64,PHN2ZyB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciIHdpZHRoPSIxMjAwIiBoZWlnaHQ9IjgwMCIgdmlld0JveD0iMCAwIDEyMDAgODAwIj48cmVjdCB3aWR0aD0iMTAwJSIgaGVpZ2h0PSIxMDAlIiBzdHlsZT0iZmlsbDojY2ZkNGRiO2ZpbGwtb3BhY2l0eTogMC4xOyIvPjwvc3ZnPg==)](https://pxhere.com/fr/photo/609217)

**Voici les produits intégrés avec l’extension Google Site Kit :**

-   [Google Analytics](https://accounts.google.com/ServiceLogin/signinchooser?service=analytics&passive=1209600&continue=https%3A%2F%2Fanalytics.google.com%2Fanalytics%2Fweb%2Fprovision%2F%3Fauthuser%3D0%23%2Fprovision&followup=https%3A%2F%2Fanalytics.google.com%2Fanalytics%2Fweb%2Fprovision%2F%3Fauthuser%3D0&flowName=GlifWebSignIn&flowEntry=ServiceLogin) : Est un service gratuit d’analyse d’audience d’un site Web, il vous permet de comprendre le comportement de votre trafic, d’observer les statistiques et les flux de votre site web en temps réel, le taux de rebond … Etc

-   [La Search Console](https://www.google.com/search?q=search+console&oq=search+c&aqs=chrome.1.69i57j0l2j69i60l3.3630j0j7&sourceid=chrome&ie=UTF-8) : Est un service gratuit de Google (ancien Google Webmaster Tools) qui permet aux webmestres de vérifier l’optimisation du référencement naturel “SEO”, et l’état de l’indexation sur Google.

-   [Google AdSense](https://www.google.com/adsense/start/?utm_medium=cpc&utm_source=google&utm_campaign=1003747-adsense-acquisition-emea-en-hybrid-rmkt-similaraudience-r1&utm_term=google%20adsense&utm_content=373139991047&gclid=CjwKCAjwq4fsBRBnEiwANTahcLMnqYGLSRJyUUpoHNHHr837SrzJgJnGS47ujwV1amEEUOOzjYy3jRoCpMkQAvD_BwE) : Est la régie publicitaire, qui utilise les sites web, blog et les vidéos YouTube comme support pour la diffusion des annonces, c’est aussi la plateforme N° 1 au monde de la monétisation.  
    

-   [Google PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights/?hl=fr) : Est un excellent outil gratuit de Google pour l’amélioration de temps des chargements des pages sur le mobile, ordinateur et tablette.

Commencez par télécharger **le kit de site Google** à partir de ce **[lien](https://sitekit.withgoogle.com/service/download/google-site-kit.zip)** : une fois l’extension téléchargée, vous allez sur le répertoire officiel des extensions, comme suite → **Extensions** → Ajouter une **Extension** → puis cliquez sur le bouton Télécharger **l’extension**.

![](https://leconceptmarketing.com/wp-content/uploads/2019/09/Capture-d%E2%80%99e%CC%81cran-2019-09-18-a%CC%80-15.43.37-1024x529.png)

Une fois l’installation effectuée, n’oubliez pas d’activer l’extension en cliquant sur le bouton **Activer**.  

![](https://leconceptmarketing.com/wp-content/uploads/2019/09/Capture-d%E2%80%99e%CC%81cran-2019-09-18-a%CC%80-15.44.08.png)

Une fois l’extension **activée**, vous aurez un message d’activation :

![](https://leconceptmarketing.com/wp-content/uploads/2019/09/Capture-d%E2%80%99e%CC%81cran-2019-09-18-a%CC%80-15.46.53-1024x174.png)

Cliquez sur le bouton : ” START SETUP & Démarrer la configuration ” pour intégrer les services de Google à votre site Web WordPress. Allez ensuite à **developers.google.com/web/sitekit** et générez votre identifiant client.

![](https://leconceptmarketing.com/wp-content/uploads/2019/09/Capture-d%E2%80%99e%CC%81cran-2019-09-19-a%CC%80-03.05.00-1024x498.png)

Une fois que vous aurez terminé, vous allez remarquer que Google détient toutes les informations nécessaires sur votre site web, et dans ce cas, la seule étape qui vous reste, c’est d’obtenir les informations d’identification OAuth, et vous faites, extrêmement la même chose pour l’authentification, la vérification de L’URL, et la search console, une fois terminé. Vous aurez un message comme suite.

![](https://leconceptmarketing.com/wp-content/uploads/2019/09/Capture-d%E2%80%99e%CC%81cran-2019-09-19-a%CC%80-03.11.11.png)

Après l’enregistrement et la validation de ces informations, vous serez amené au menu de l’extension pour ajouter le tracking ID, les codes …  de chaque produit Google.
