John Mueller, est un webmaster trends analyst chez Google, a précisé lors d’une discussion sur Reddit (un site web communautaire d’actualités)
Avec un spécialiste en SEO qui cherchait des conseils sur la création d’un plan de site pour un site web contenant des millions de produits.
En effet, John Mueller précisé, que le plan des sites pour les grands sites Web « sitemap.xml » ne doivent pas être créés manuellement.
Il est connu que le sitemap est un plan de site conçu spécifiquement pour les moteurs de recherche. Il permet de lister les contenus stratégiques d’un site Web et voici ce que Mueller suggère de faire à la place : vous devez obtenir (le Sitemap) directement depuis le CMS.
