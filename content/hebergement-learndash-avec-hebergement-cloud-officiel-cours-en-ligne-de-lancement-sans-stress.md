## Qu’est-ce que Learndash :

Learndash est (auparavant uniquement) un plugin WordPress qui convertit votre site Web en un système de gestion de l’apprentissage. De cette façon, vous pourriez vendre des cours en ligne sur votre site WordPress. Il offre une intégration avec toutes les passerelles de paiement populaires et est la solution LMS #1 de WordPress.

## Qu’est-ce que le cloud Learndash :

Learndash cloud est la toute dernière solution gérée par l’équipe Learndash, où vous n’avez pas besoin d’héberger Learndash sur votre serveur. Tout est hébergé sur le serveur cloud Learndash et vous pouvez choisir parmi les modèles et plugins disponibles pour personnaliser le site Web.

Il s’agit d’une meilleure alternative à Learndash auto-hébergé pour les instructeurs et les entraîneurs qui souhaitent se concentrer sur la création et le marketing de contenu plutôt que sur la gestion de la technicité du site Web.

## Différence entre Learndash Cloud Vs. Plugin WordPress Learndash :

### Nuage Learndash :

Lorsque vous utilisez le cloud Learndash, vous n’avez pas à vous soucier de l’hébergement Web et de la maintenance de WordPress. Considérez le cloud Learndash comme Kajabi, Thinkific et une autre solution hébergée dans le cloud, qui ne vous oblige pas à gérer des logiciels open source complexes tels que WordPress. Learndash Cloud fonctionne sur WordPress, mais il s’agit d’un hébergement Learndash géré. Cela signifie que vous n’avez pas à vous soucier de la maintenance quotidienne, de la sécurité et des autres aspects de votre hébergement WordPress.

Tout ce que vous avez à faire est de souscrire un abonnement de 29 $/mois au cloud Learndash et de lancer votre cours en ligne avec leur processus d’intégration facile.

Remarque : Le cloud Learndash est assorti d’une garantie de remboursement intégral de 15 jours.

### Plugin WordPress Learndash :

Le plugin Learndash WordPress vous oblige à acheter leur plugin pour 199 $ / an et à l’utiliser sur un site Web WordPress auto-hébergé. Vous devez acheter un hébergement pour Learndash, et certains des hébergements populaires de Learndash sont :

Il s’agit principalement d’un hébergement WordPress géré, qui coûte plus de 25 $/mois.

Pour exécuter un cours en ligne du plugin Learndash WordPress, vous paieriez :

199 $ (plugin WordPress) + 300 $ (hébergement Learndash) = 499 $ (c’est le coût minimum, car vous payez peut-être pour la personnalisation + plus de plugins).

J’utilise actuellement le plugin WordPress Learndash pour gérer mon cours en ligne, hébergé sur l’hébergement Kinsta. Vous pouvez voir le cours ici à [https://pro.shoutmeloud.com](https://pro.shoutmeloud.com)

## Ce qui est mieux? – Hébergement Learndash Cloud ou plugin Learndash WordPress :

Si vous êtes quelqu’un qui n’a jamais utilisé WordPress et qui est un solopreneur (travaillant seul), il vaut mieux utiliser Learndash Cloud. Il vous donne presque tout, avec moins de maux de tête pour l’entretenir.

En termes de prix, il y a une différence significative, car vous paieriez 149 $ / an de plus pour **Nuage Learndash**. Cela pourrait être un dealbreaker pour un créateur sensible au prix. Cependant, lorsque vous incluez le prix de l’hébergement (comme mentionné ci-dessus), vous gagnerez du temps.

Cependant, si vous payez déjà pour un compte d’hébergement, ce coût s’additionne, car vous ne paierez peut-être pas de supplément pour l’hébergement du site Web Learndash.

Cependant, si vous aimez la personnalisation avancée de votre site Web et aimez le contrôle, vous devez utiliser le plugin WordPress Learndash. Pour l’instant, je vais continuer à développer mon cours en ligne existant sur le plugin WordPress Learndash, et le moment venu, j’envisagerai de passer à Learndash Cloud.
