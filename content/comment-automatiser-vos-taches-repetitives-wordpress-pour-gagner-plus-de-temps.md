## Auto-post depuis d’autres sites web et médias sociaux :

Ce plugin peut automatiquement mettre à disposition un contenu unique. Si vous êtes un blogueur, alors je peux vous assurer que ce pourrait être le plugin WordPress Autoblog que vous recherchiez, quelques-uns des principaux sites web compatibles seront discutés ci-dessous

- **Spintax :** Le plugin WordPress Autoblog peut importer à partir du formulaire Spintax. Ce plugin peut dériver autant d’articles que souhaité de spintax et les publier automatiquement sur WordPress.
- **Flux RSS :** Ce plugin peut importer le contenu complet, l’auteur, les tags, les catégories, et l’image vedette à partir d’un flux RSS. Il suffit d’ajouter n’importe quel flux RSS pour que le plugin le copie. Son scraper de page unique peut importer la partie désirée à partir de n’importe quelle URL, il a la capacité de continuer à surveiller cette partie et de faire des mises à jour si le post change.
- **Amazon :** Les produits Amazon peuvent être importés par le biais de mots-clés ou de nœuds de navigation avec un support complet de WooCommerce, y compris la galerie et les prix. La mise à jour des prix et les liens d’affiliation sont définis automatiquement.
- **eBay :** Tout comme les produits Amazon, le plugin WordPress Automatic peut importer des produits eBay par mots-clés ou par le vendeur. Le support complet de WooCommerce, la galerie de produits, les prix et les liens d’affiliation sont définis automatiquement.

De plus, il fonctionne avec les médias sociaux. Il peut importer les profils Facebook personnels, les groupes ouverts ou fermés, surveiller et importer tous les nouveaux messages avec des options de filtrage étendues pour filtrer par date, type, et plus encore.

Il peut publier des vidéos de YouTube par mot-clé, nom d’utilisateur ou par liste de lecture spécifique et les publier automatiquement sur votre site Web WordPress.

Il peut importer depuis Instagram par mots-clés, hashtags, ou un profil spécifique, y compris les commentaires et les tags. Veuillez noter qu’il ne peut importer que des posts populaires et les derniers éléments.

Twitter aussi n’est pas en reste, il peut importer automatiquement des contenus twitter sur votre site WordPress en ciblant des mots-clés, des hashtags, ou un profil spécifique.

Extraction de parties spécifiques des articles originaux

Le plugin automatique de WordPress peut extraire les parties indiquées de l’article original et les concaténer pour les publier sur votre site Web WordPress.
