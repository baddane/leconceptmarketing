Voici des signes simples indiquant qu’un site Web a été piraté. Vous n’avez pas besoin d’engager un expert en sécurité pour les dévoiler pour vous. Malheureusement, un site Web piraté peut arriver à toute personne qui ne fait pas attention ou ne publie pas régulièrement des correctifs de sécurité.

L’époque où les attaques de piratage étaient inhabituelles et n’arrivaient qu’aux grandes entreprises est révolue. Au contraire, le piratage de particuliers et de petites ou moyennes entreprises est devenu un environnement lucratif pour de nombreuses personnes disposant de connaissances informatiques suffisantes.

C’est pourquoi le piratage d’un site Web est un problème auquel presque tout le monde est confronté dans le monde moderne. Mais, malheureusement, souvent les entreprises et même les gestionnaires de sites Web modernes reconnaissent le problème lorsqu’il est déjà trop tard, et des données précieuses (voire de l’argent) sont perdues.

Nous voulons vous montrer comment vous pouvez détecter que votre site Web a été piraté ou qu’il y a eu des activités suspectes, et ce que vous pouvez faire pour prévenir de telles vulnérabilités.

## 1.Le navigateur vous avertit du piratage :

Votre site Web ou votre navigateur peut afficher des signaux d’activités suspectes ou des écrans d’avertissement indiquant que le site Web a été victime d’une attaque de phishing. Dans ce cas, il est préférable d’évaluer le problème immédiatement et d’essayer de le résoudre avant que vos utilisateurs ne le découvrent.

[Les attaques de phishing ](https://www.ssi.gouv.fr/entreprise/principales-menaces/cybercriminalite/attaque-par-hameconnage-phishing/#:~:text=L'hame%C3%A7onnage%20reste%20l'un,lui%20d%C3%A9rober%20de%20l'argent.)sont des escroqueries d’ingénierie sociale où des criminels se font passer pour des organisations légitimes par le biais de courriels, de messages textuels, de publicités ou d’autres moyens pour voler des informations sensibles. Ils tentent de voler des informations personnelles, des informations sur les cartes de crédit, des numéros de sécurité sociale, des comptes de messagerie, des comptes bancaires… Vous voyez le genre.

Une bonne pratique consiste à établir un plan pour ces événements qui contient les mesures suivantes :

- **Sauvegarder et fermer le site Web.**
- **Restaurer le site Web à partir d’une sauvegarde**
- **Effectuer une enquête médico-légale sur les problèmes de sécurité.**

## 2.Votre fournisseur d’hébergement met le site hors ligne :

Souvent, vous ne remarquez pas que vous avez été piraté, mais votre fournisseur le sait. Soit vos clients les ont contactés, soit leur propre service de sécurité informatique surveille tous les sites Web fournis. Malheureusement, ils mettent souvent votre site hors service sans avertissement préalable.

Cela peut détruire la confiance des deux côtés de votre chaîne de valeur, celle de vos clients et celle du fournisseur de services. Dès que vous constatez que votre site a été retiré, prenez contact avec votre prestataire de services et informez vos utilisateurs en temps utile.

## 3.Les clients vous contactent :

Si vous avez de la chance, vos clients ne contacteront pas directement votre fournisseur de site Web, mais vous appelleront ou utiliseront le formulaire de contact de votre site Web.

Bien sûr, cela signifie que ces utilisateurs ne sont pas satisfaits de votre site Web, mais cela montre aussi qu’ils ont suffisamment confiance en vous pour résoudre le problème.

C’est le moment de regagner cette confiance. Montrez-leur votre soutien et essayez d’aller au fond de ce problème particulier. Vous pourriez ainsi découvrir des failles de sécurité **(code malveillant ou activités malveillantes**) dont vous n’auriez jamais eu connaissance.

## 4.Google signale votre site Web :

Google, ou tout autre moteur de recherche, vérifie en permanence les sites Web qu’il affiche. S’ils constatent des tendances inhabituelles ou des changements notables, ils peuvent exclure votre site Web des résultats de recherche.

Dans certains cas, ils mettent simplement un drapeau sur vos liens indiquant “Ce site peut être piraté” ou “Ce site peut nuire à votre ordinateur”, qui apparaît dans les recherches sur Internet.

C’est pourquoi il est essentiel de consulter régulièrement votre Google Search Console. Ou essayez de rechercher votre site Web de temps en temps afin de trouver ces liens peu attrayants avant vos clients, fournisseurs, prestataires de services ou autres partenaires commerciaux.

## 5.Le site se charge plus lentement que d’habitude :

Si vous avez l’impression que le chargement de votre [site Web](https://leconceptmarketing.com/comment-creer-un-site-web-etape-par-etape-pour-les-debutants/) est anormalement long, cela peut être dû à une activité accrue sur le site ou sur l’ensemble du serveur.

Un logiciel malveillant peut utiliser les ressources de votre serveur. Par conséquent, si le chargement de votre site Web prend deux fois plus de temps (ou même plus) que d’habitude, il s’agit de signes d’alerte et vous devriez vérifier si votre serveur ne présente pas d’activité inhabituelle ou malveillante ou de logiciel nuisible.

## 6.Vos courriels sont envoyés dans les spams :

Le nombre de personnes ayant répondu à votre dernière lettre d’information était anormalement bas ?

C’est peut-être parce que vos e-mails sont envoyés dans le dossier spam de votre client.

Lorsque des pirates informatiques envoient des listes de courriers indésirables via votre site web, celui-ci peut être placé sur la liste noire de votre fournisseur de messagerie, alors assurez toujours un suivi de vos activités de marketing.

## 7. Votre site Web est utilisé pour des redirections ou des publicités non désirées

Cela peut être le signe que votre site web est compromis par [une attaque XSS (Cross-Site-Scripting)](https://www.kaspersky.fr/resource-center/definitions/what-is-a-cross-site-scripting-attack).

Les pirates et les mauvais acteurs tentent de gagner de l’argent en diffusant des publicités sur des sites ciblés ou en envoyant vos clients sur le site d’un concurrent. Tout comme les redirections indésirables, les pirates peuvent essayer de tirer profit de l’hébergement de fenêtres publicitaires payantes sur votre site Web.

Une visite régulière de votre site Web peut permettre de détecter rapidement le problème et vous apporter une certaine tranquillité d’esprit.
