Saviez-vous que près de la moitié du trafic mondial des sites web provient d’appareils mobiles ? Les gens ne se contentent pas de naviguer sur le Web sur mobile, ils créent également du contenu en utilisant les applications mobiles de plateformes telles que WordPress, Facebook et d’autres sites de médias.
Au fil des ans, les applications mobiles WordPress ont été considérablement améliorées pour vous aider à publier facilement du contenu et à gérer votre site Web à l’aide d’un appareil mobile. L’application WordPress est déjà disponible pour les appareils Android et iOS.

Dans cet article, nous allons vous montrer comment utiliser l’application WordPress sur votre iPhone, iPad, Android et autres appareils mobiles.

## Pourquoi utiliser l’application WordPress sur iPhone ou iPad ?

L’application WordPress vous permet de créer du contenu et de gérer votre site Web de n’importe où dans le monde, en particulier lorsque vous êtes en voyage.
Vous pouvez capturer et télécharger des photos, enregistrer et télécharger une vidéo, écrire des articles de blog rapides tout en prenant le train ou le bus, en vous promenant ou en traînant avec des amis. Vous pouvez emporter votre site WordPress dans votre poche.
Par défaut, la zone d’administration de WordPress est entièrement responsive et fonctionne bien sur les navigateurs mobiles.

Toutefois, cette interface utilisateur n’est pas optimale pour une utilisation mobile.
En revanche, l’application WordPress est conçue pour être conviviale, optimisée pour les mobiles et facile à utiliser. L’interface utilisateur est intuitive, ce qui fait de l’utilisation de l’application WordPress un plaisir.
Écrire sans clavier physique était un problème pour de nombreux blogueurs. L’application combine le clavier tactile natif de votre appareil avec les boutons de formatage de WordPress, ce qui rend la rédaction des articles sur les appareils tactiles simple et facile.

## De quoi avez-vous besoin pour utiliser l’application mobile WordPress ?

Contrairement aux autres applications mobiles, vous devez disposer d’un site ou d’un blog WordPress avant de pouvoir utiliser l’application WordPress.
L’application WordPress fonctionne à la fois avec la plateforme gratuite d’auto-hébergement WordPress.org et avec le service d’hébergement de blog WordPress.com.
Pour plus de détails, consultez notre comparaison côte à côte de WordPress.com et WordPress.org.

## Configuration de votre site Web pour les applications mobiles WordPress

Vous aurez besoin des deux éléments suivants pour connecter votre site Web à l’application WordPress :
- Le plugin JetPack sur votre site Web
- Un compte WordPress.com gratuit
Commençons.
Tout d’abord, vous devez installer et activer le plugin JetPack sur votre site Web. Pour plus de détails, consultez notre guide étape par étape sur la façon d’installer un plugin WordPress.

## Configuration de l’application WordPress sur votre appareil mobile
Tout d’abord, vous devez installer l’application WordPress sur votre appareil. Elle est disponible pour Android, iOS (iPhones et iPads), Windows, MacOS et Linux.

Ensuite, vous devez ouvrir l’application et vous connecter à votre compte WordPress.com.
Après cela, l’application se connectera et récupérera les informations de votre site web.

## Modification des articles de blog avec l’application WordPress
L’application WordPress est dotée d’une interface utilisateur intuitive qui vous permet de créer/modifier facilement les articles de blog et les pages de votre site Web.
Vous pouvez visualiser tous vos articles en cliquant sur le menu Articles de blog dans le tableau de bord de l’application. Vous obtiendrez ainsi une liste de vos articles de blog récents.

## Télécharger et gérer les fichiers multimédias à l’aide de l’application WordPress
L’application WordPress vous permet de gérer et de télécharger facilement des photos/vidéos depuis votre téléphone.
Vous pouvez télécharger des médias tout en rédigeant des articles, ou vous pouvez directement lancer la médiathèque à partir du tableau de bord de l’application.

Cela lancera la bibliothèque multimédia de WordPress, et vous pourrez voir tous les fichiers multimédia de votre bibliothèque. Vous pouvez modifier les fichiers multimédias, les supprimer, et même télécharger de nouvelles photos et vidéos depuis votre téléphone en utilisant le bouton Ajouter.

## Est-il possible de faire fonctionner WordPress entièrement à partir de l’application ?
Non. Actuellement, il n’est pas possible de faire fonctionner efficacement un site WordPress en utilisant uniquement l’application WordPress.
Par exemple, vous ne pouvez pas gérer les plugins à partir de l’application. Les plugins sont une partie essentielle d’un site WordPress et vous en avez besoin pour étendre les fonctionnalités de votre site.
Vous ne pouvez pas non plus accéder aux types d’articles personnalisés, aux options de référencement, aux images de couverture, aux blocs créés par les plugins, etc.

### Pourquoi et quand utiliser l’application WordPress ?
Bien que l’application WordPress ne soit pas suffisante pour faire fonctionner efficacement l’ensemble du site Web, elle fait un excellent travail en vous fournissant une interface facile à utiliser pour rédiger du contenu, télécharger des photos et gérer les commentaires lorsque vous êtes loin de votre ordinateur.
Elle peut également être utilisée lorsque vous voyagez dans des endroits où la connectivité est faible. Vous pouvez utiliser certaines des fonctions de l’application hors ligne, ce qui vous permet d’enregistrer le contenu sous forme de brouillons locaux.
L’application peut être utilisée comme un compagnon pour créer du contenu en déplacement et gérer les tâches de routine comme la modération des commentaires.
