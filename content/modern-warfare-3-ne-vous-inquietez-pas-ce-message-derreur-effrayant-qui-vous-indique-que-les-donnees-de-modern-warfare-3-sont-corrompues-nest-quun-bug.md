# Modern Warfare 3 : Ne vous inquiétez pas, ce message d’erreur effrayant qui vous indique que les données de Modern Warfare 3 sont corrompues n’est qu’un bug

Vous avez sans doute récemment démarré Modern Warfare 3 afin de vous plonger dans la première grande mise à jour de contenu saisonnière du jeu. Avec toute une série de nouvelles cartes, de nouveaux opérateurs et de nouvelles armes, sans oublier une expérience Warzone remaniée, il y a de nombreuses bonnes raisons de jouer dès maintenant à la première saison du dernier Call of Duty.
Cependant, si vous êtes comme moi, vous avez été immédiatement accueilli par un message d’erreur terrifiant qui vous a fait fermer le jeu de peur. Le message menaçant se lit comme suit : &#8220;Vos données sont corrompues ou n’ont pas été téléchargées correctement. Vous devez réinitialiser votre rang et vos déverrouillages pour continuer&#8221;, ce qui est probablement la dernière chose que vous voudriez entendre après avoir passé les deux derniers mois à grinder pour déverrouiller vos armes préférées et atteindre le rang maximum.
Deux choix s’offrent à vous lorsque cette erreur apparaît : cliquer sur &#8220;oui&#8221; pour apparemment effacer votre progression ou cliquer précipitamment sur &#8220;non&#8221;, ce qui ferme immédiatement le jeu. Bien que je n’aie pas voulu prendre le risque à l’époque, les développeurs de Modern Warfare 3 ont heureusement confirmé que l’apparition de ce message n’est qu’un bug et qu’il n’y aura aucune répercussion durable si vous cliquez dessus pour revenir dans le jeu.

Dans un message publié sur la page Twitter officielle des mises à jour de Call of Duty, le message d’erreur a été décrit comme &#8220;incorrect&#8221; et l’équipe a assuré que &#8220;votre rang, vos déverrouillages et vos achats ne sont pas perdus&#8221;. Malheureusement, ils précisent que vos chargements seront probablement affectés.
