Aujourd’hui, les spams font partie du quotidien des blogueurs et créateur de sites, une sorte de communications électroniques massives parfois envoyé par des robots , logiciels ou encore une des programmes spécifiques , et si un jour vous activez les commentaires sur vos articles, vous devrez faire face à des spammeurs, c’est sure !!! Donc notre objectif, c’est faire face à une telle situation qui pourra impacter notre site dans le futur.

![5 Astuces Pour  Protéger  Votre Site WordPress Contre Les Spams](https://leconceptmarketing.com/wp-content/uploads/2019/01/image-3.png)

Parfois, il est totalement impossible de contrôler totalement le spam, mais vous pouvez faire beaucoup de chose pour le retirer. Pour ceux qui utilisent WordPress, vous pouvez y mettre des actions pour controler, retirer, maquer ou bloquer ces commentaires avant que vos visiteurs ne les observent.  Et pour cela, vous pouvez  utiliser un puissant plugin anti-spam pour contrôler la situation.

Le spam est utilisé pour designer un contenu indésirable ” des commentaires, courriel indésirable, des formulaires, ex…” Qui contient des backlinks ou des liens retour vers d’autres sites web, d’une manière non sollicitée. Ces sites web, envisagent, vous vendre n’importe quoi, des liens porno, mais aussi des softwares & logiciels malveillants pour but d’affecter vos terminaux ” téléphone, ordinateur ou tablettes “, et l’architecture de wordpress n’est pas une exception, Cependant, tout les spammeurs visent wordpress… Mais aujourd’hui nous allons vous présenter les actions, outils et plugins peuvent vous aidez sur wordpress. Découvrez, donc comment mettre un point d’arrêt au spam et reprendre le contrôle de votre site WordPress…

### 1. Commencer par contrôler les commentaires sur tous les articles que vous publiés :

![](https://leconceptmarketing.com/wp-content/uploads/2019/01/wordpress-commentaires-1024x583.jpg)

sur la rubrique **Réglages – Discussion** sur votre tableau de bord wordpress : cochez l’option, le commentaire doit être approuvé manuellement comme ça, c’est à vous d’approuver les commentaires sur votre site web.

NB : Le simple fait de refuser les commentaires  n’arrêtera pas un flux de commentaires sur vos publications et Pour pouvoir supprimer tous les commentaires de tous les articles existants, visitez le Tableau de bord – option : **Commentaires**.

Ici, vous pouvez sélectionner les commentaires que vous voulez supprimer, cliquez sur **Actions groupées**, sélectionnez «**Déplacer dans la corbeille**», puis cliquez sur le bouton Appliquer.

#### 2- Activer le plugin [AKismet](https://wordpress.org/plugins/akismet/) sur votre wordpress :

![Activer le plugin AKismet sur votre wordpress ](https://leconceptmarketing.com/wp-content/uploads/2019/01/Capture-d%E2%80%99e%CC%81cran-2019-01-22-a%CC%80-07.09.16-1024x257.png)

par défaut, le plugin [Akismet](https://wordpress.org/plugins/akismet/) est installé sur votre compte wordpress, c’est une sorte de solution proposée par wordpress lui-même, mais il suffit juste l’activer pour en bénéficier de ses fonctions, il va vous permettre de contrôler les spams et les commentaires sur votre site web, les activer ou les désactiver…On tiens à vous informer qu’ils existent des plugins pareilles possédant la même fonctionnalité telle que le fameux : [WP Bruiser](https://wordpress.org/plugins/goodbye-captcha/)  

#### 3. Retirer les commentaires sur les articles manuellement :

![Retirer les commentaires sur les articles manuellement sur wordpress](https://leconceptmarketing.com/wp-content/uploads/2019/01/autoriserles-commentaires-sur-wordpress.jpg)

au niveau de vos articles, qu’on vous modifiez les paramètres de vos articles, vous avez une rubrique pour soit, activer les commentaires soit pour les désactiver…
